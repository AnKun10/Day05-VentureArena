Privacy Policy

Effective date: July 30, 2026 · Last updated: July 30, 2026

An automatic deletion schedule is not implemented in the current code. The published retention period is 90 days.

Scope

This policy describes the current Companion Discord Bot implementation. The public Discord application name is Personalized Discord Companion Agent.

Data We Collect or Process

For messages from explicitly configured source channels and forum threads, the ingestion worker stores the following in a local SQLite database:

  • Discord message ID and channel ID;
  • the message author’s Discord user ID, display name, and non-default role names;
  • message and forum-thread content, the source group, creation time, and the Discord jump link;
  • attachment file names and attachment URLs, when Discord supplies them; and
  • forum-thread messages when the configured source is a forum channel.

The current bot database does not separately store a server ID or a thread ID. A stored Discord jump link may contain Discord identifiers. Attachments are not downloaded or stored as files by this bot; only their names and URLs are stored.

When you use /ask, the bot sends the question to the local Companion API. The API writes an operational trace containing the question, answer decision, answer text, citations, confidence, timestamp, and, when applicable, the AI-provider name. If the system cannot answer, it also stores the question, optional class name, and timestamp in an unanswered-question queue for a TA digest. Other slash commands are processed to respond to the interaction; the current code does not create a separate database record for them. The /ta-digest command uses the requesting Discord user ID to find that TA’s assigned classes and may send the resulting digest by Discord direct message.

Demo content intentionally entered into a demo Discord server is processed and stored in the same way as other configured source content. Do not enter sensitive personal information into a demo server.

Why We Process Data

We process this data to ingest configured course sources, produce a digest with links back to the original Discord content, answer course logistics questions from source material, record unanswered questions for the relevant TA, operate the Service, and diagnose its answers.

Storage and Retention

Ingested posts are stored in a local SQLite database. Operational traces are stored as local JSON files, and unanswered questions are stored in SQLite. The current code has no automatic deletion process or configured retention duration. Records will be retained for 90 days, unless a longer period is required to resolve a security issue or legal obligation.

Third-party AI Providers

When an answer is found, the backend may send your /ask question and the selected official source excerpt to the first available provider in its configured fallback order. The current code supports OpenAI, Google Gemini, OpenRouter, and Cerebras. The provider that receives a particular request depends on the deployment configuration and provider availability. The bot does not send Discord bot tokens, client secrets, or API keys to those providers.

Sharing and Sale of Personal Data

We do not sell personal data. We share data only as needed to operate the Service: with Discord for Discord interactions and, when the AI answer route is used, with the configured AI provider as described above. A TA digest is sent only to the Discord account mapped to the relevant course class.

Data Security

The Service limits ingestion to configured channels and uses local files and databases for operational data. Access should be limited to authorized operators. No security measure is perfect, and you should not submit sensitive information through the Service.

Your Access and Deletion Requests

To request access to or deletion of data associated with you, email bopbin@gmail.com with your Discord user ID, the relevant server/channel or message link, and the request type. We may need to verify that you control the Discord account before acting. Deletion may be limited where retention is necessary for security, legal obligations, or an unresolved course-support request.

Children’s Privacy

The Service is not directed to children under the age at which they can independently use Discord under applicable law. If you believe a child has provided personal data through the Service, contact us so we can review and address the request.
